# 台灣好味島

22 縣市名產與景點的 3D 台灣島。點一格縣市，看它的名產、景點、評價好的店家（Google 地圖 4.2★ 以上），還有可以和長輩一起聊的話題。

- **到處去看看**：自由逛島，名產／景點點開有 3–5 個特色、Google 圖片、YouTube、短影音、Google 地圖連結。
- **任務模式**：選一個角色（醫師、護理師、照顧服務員、工程師…），在十字路口抽任務卡，每張 4 題（猜特產 → 猜縣市 → 猜景點 → 景點問答），答完角色會沿著步道走到那個縣市；一局 10 張卡、40 題。
- 操作：按住拖曳移動地圖、滾輪／兩指縮放、右鍵／兩指轉動旋轉，右下角有視角按鈕。

網址：https://mattsue1003.github.io/taiwan-taste-island/

單一 HTML，three.js 0.147 由 jsDelivr 載入。原始碼與資料（data.json、quests.py、features_*.json、shops_google.json）在作者本機的 `台灣名產島/` 資料夾，`./build.sh` 重新產生 index.html。店家評分為 2026 年 10 月 Google 地圖資料，請以現場為準。
